# Three Sisters Accounting

The website for [threesistersaccounting.com](https://threesistersaccounting.com), a women-owned accounting firm in Bend, Oregon.

## Local preview

Open `index.html` directly in a browser, or run a local static server from the repository root:

```sh
python3 -m http.server 8000
```

The GitHub Actions workflow in `.github/workflows/pages.yml` deploys the site to GitHub Pages whenever `main` is updated.
