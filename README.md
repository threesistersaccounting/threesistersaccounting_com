# Three Sisters Accounting

This repository contains the website for [Three Sisters Accounting](https://threesistersaccounting.com), a women-owned accounting firm based in Bend, Oregon.

Founded by Lisa Benroeck, Three Sisters Accounting helps Central Oregon businesses and individuals feel more confident about their finances. The firm provides thoughtful, practical support across bookkeeping, payroll, tax preparation, tax filing, and ongoing financial guidance.

## Website

The site is a lightweight, responsive static website designed to introduce the firm, explain its services, and make it easy for prospective clients to get in touch with Lisa.

The main site files are:

- `index.html` for the page structure and content
- `styles.css` for the visual design and responsive layout
- `.github/workflows/pages.yml` for GitHub Pages deployment

Updates pushed to `main` are published through GitHub Actions when GitHub Pages is enabled for the repository.
